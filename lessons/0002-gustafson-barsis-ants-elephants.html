Gustafson-Barsis and ants versus elephants

After this lesson you can solve Task 1 of the exercise sheet (Barlas 1.8) and decide from the wording of a question which of the two laws to use.

Warm-up from memory

Before reading on, write Amdahl's formula on paper without looking it up. Then answer.

A sequential program has α = 0.8. What speedup does Amdahl's law give on N = 8 CPUs?

1 / ((1 − 0.8) + 0.8 / 8) = 1 / (0.2 + 0.1) = 1 / 0.3 ≈ 3.33. Covered in lesson 1.

The rebuttal: nobody keeps the problem the same size

Amdahl asks: "I have a fixed job. How much faster does it finish on N CPUs?" Gustafson and Barsis observed that real users do not behave like that. Give an ML team 8 GPUs instead of 1 and they do not train the same small model 8 times faster. They train a bigger model, or on more data, in the same wall-clock time. The problem grows with the machine. slide 1-33

So they start from the other end: a parallel program that takes time T on N CPUs. For a fraction α of that time it runs on all N machines; for the remaining 1 − α it runs sequentially. How long would one CPU need for the same work?

The sequential part takes the same (1 − α)T. The parallel part was done by N machines for αT each, so one machine needs N times as long.

Gustafson-Barsis · slide 1-34 tseq = (1 − α)T + N · α · T   ⇒   speedup = tseqT = (1 − α) + N · α
Efficiency · slide 1-34 efficiency = speedupN = 1 − αN + α

There is no ceiling: the speedup is a straight line in N, and the efficiency never falls below α. Compare the two curves for the same α below. slide 1-34

Same symbol, different measurement. In Amdahl's law α is a fraction of the sequential run time. In Gustafson-Barsis it is a fraction of the parallel run time. That is why the same program does not contradict itself under the two laws.

Which law does a question want?

The wording saysUse
"A sequential application with an x% sequential part is to be accelerated…"Amdahl
"A parallel application running on N CPUs spends x% of its total time in sequential execution…"Gustafson-Barsis

Neither is "right": both assume zero communication overhead, which is too optimistic. slide 1-37

Ants versus elephants

Should you buy one powerful CPU (an elephant, type A) or many cheap ones (ants, type B)? Let the program take TA on A and TB on one B. Then A is r = TB / TA times faster. Apply Amdahl to NB ants and compare against the elephant:

Speedup of NB cheap CPUs over one CPU of type A · slide 1-31 speedup = TA(1 − α)TB + αTB / NB = 1(1 − α) r + α r / NB
With infinitely many ants · slide 1-32 limit = 1(1 − α) r   so the ants never win if   r ≥ 11 − α

Example from the slide: with α = 0.9 and r = 10 the limit is exactly 1, so even infinitely many ants only tie with one elephant. slide 1-32

Practice

Pen and paper first. Two decimals are enough.

A parallel program runs on N = 8 CPUs and spends α = 0.8 of its time on all machines. What is its speedup according to Gustafson-Barsis?

(1 − 0.8) + 8 · 0.8 = 0.2 + 6.4 = 6.6. Same α and N as the warm-up, where Amdahl gave 3.33.

Same program. What is its efficiency, in percent?

6.6 / 8 = 0.825, or (1 − 0.8) / 8 + 0.8 = 0.025 + 0.8 = 0.825. It can never drop below α = 80%.

"A parallel job running on 16 CPUs spends 10% of its total time in sequential code. What is the speedup over one CPU?" Which law fits?

The percentage is measured on the parallel run, on N CPUs. That is the Gustafson-Barsis starting point: speedup = 0.1 + 16 · 0.9 = 14.5.

Exercise Sheet 1, Task 1 (Barlas 1.8): a parallel application running on 10 CPUs spends 15% of its total time in sequential execution. How many times faster must a single CPU be to run it completely sequentially in the same total time?

N = 10, α = 0.85. One ordinary CPU needs tseq = (1 − α)T + NαT = 0.15T + 8.5T = 8.65T. To finish in T, the single CPU must be 8.65 times faster. That is exactly the Gustafson-Barsis speedup.

A program has α = 0.95. CPU A is r = 4 times faster than CPU B. What speedup do NB = 16 CPUs of type B achieve over one CPU of type A?

1 / ((1 − 0.95) · 4 + 0.95 · 4 / 16) = 1 / (0.2 + 0.2375) = 1 / 0.4375 ≈ 2.29.

Same program and CPUs. What is the upper bound on that speedup with unlimited CPUs of type B?

1 / ((1 − α) r) = 1 / (0.05 · 4) = 5.

Barlas 1.6: an application has a 5% non-parallelizable part. Machine X has 4 CPUs, each running the application alone in 1 hour. Machine Y has 16 CPUs, each running it alone in 2 hours. Which machine finishes first, and in roughly what time?

α = 0.95, Amdahl times. X: 1 h · (0.05 + 0.95 / 4) = 0.2875 h ≈ 17 min. Y: 2 h · (0.05 + 0.95 / 16) = 0.21875 h ≈ 13 min. The ants win here because r = 2 is far below 1 / (1 − α) = 20.

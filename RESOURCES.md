# Advanced Computer Architecture Resources

## Knowledge

- [Slides: ACA 2026W 01 Introduction (Barlas Ch. 1, modified by H. Weber)](materials/ACA%202026W%2001%20Introduction.pdf)
  The authoritative source for the test. Use for: Flynn's taxonomy, speedup, efficiency, scalability, Amdahl, Gustafson-Barsis.
- [Slides: ACA 2026W 02 Program design (Barlas Ch. 2, modified by H. Weber)](materials/ACA%202026W%2002%20Program%20design.pdf)
  Use for: PCAM, decomposition patterns D1 to D6, geometric decomposition costs, prefix-sum, pipeline analysis, program structure patterns.
- [Seminar Exercise Sheet 1](materials/ACA%202026W%20Seminar%20Exercise%20Sheet%201.pdf) and [Barlas Exercises Ch. 1](materials/Barlas%20Exercises%20Ch1.pdf)
  The "corresponding seminar work" named in the test announcement. Use for: the most likely style of calculation questions.
- Book: _Multicore and GPU Programming: An Integrated Approach_ by Gerassimos Barlas (Morgan Kaufmann)
  The textbook the slides are built from. Use for: full derivations the slides skip, for example section 2.3.4 for the prefix-sum analysis.
- [Book: _Designing and Building Parallel Programs_ by Ian Foster (online)](http://www.mcs.anl.gov/~itf/dbpp/text/book.html)
  Origin of the PCAM methodology, linked from slide 2-3. Use for: deeper PCAM examples.
- [TOP500 list](https://www.top500.org/lists/top500/2026/06/)
  Linked from slide 1-9. Use for: current supercomputer facts (Barlas exercises 1.1 to 1.3).

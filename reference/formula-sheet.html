Set 1: the two laws

Amdahl (1967)Gustafson-Barsis (1988)
Starting pointA sequential program taking T on one CPU. Fixed problem size.A parallel program taking T on N CPUs. Problem size grows with N.
α isthe fraction of the sequential run that can be parallelizedthe fraction of the parallel run spent on all machines
Timestpar = (1 − α)T + αT / Ntseq = (1 − α)T + N · α · T
Speedup1 / ((1 − α) + α / N)(1 − α) + N · α

Slides1-28, 1-291-33, 1-34

Both assume zero communication overhead, so neither is "right" (slide 1-37). Telling them apart in an exercise: a program described as sequential, to be accelerated is Amdahl. A program described as running on N CPUs, spending x% of its time sequentially is Gustafson-Barsis.

Ants versus elephants · slides 1-31, 1-32 r = TB / TA  (CPU A is r times faster than B)  ·  speedup = 1(1 − α) r + α r / NB  ·  limit = 1(1 − α) r

NB cheap CPUs never beat one CPU of type A if r ≥ 1 / (1 − α). Example: α = 0.9 and r = 10.

D3 Geometric decomposition, N × N cells, P nodes (slides 2-22 to 2-25)

Computing cost per node and stepCommunication cost per node and step

1-D is better than 2-D if · slide 2-25 tstart > tcomm · N · (1 − 2 / √P)

Derivation: the computing costs are equal, so compare communication only. 2(tstart + tcommN) < 4(tstart + tcommN / √P) gives 2 tcommN − 4 tcommN / √P < 2 tstart; divide by 2.
